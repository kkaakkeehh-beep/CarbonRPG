# CarbonRPG — 炭素の勇者

有機化学 RPG の試作版です。主人公は 4 本の手を持つ sp³ 炭素「カーボ」。
仲間（結合パートナー）が持ち込む **試薬カード** と、自分で選ぶ **溶媒・温度** の組み合わせで、暴走した分子を目的の化合物に変えていきます。

**第1章「求核の森」**（6 戦闘・ボス 1 体）を遊べます。

## 遊び方

- ブラウザで `index.html` を開くだけで動きます（ビルド不要）。
- GitHub Pages で公開する場合: リポジトリの **Settings → Pages → Branch: `main` / `(root)`** を選んで保存。

### ルール

1. **仲間を 4 人選ぶ**（6 人から）。それぞれ 3 枚のカードをデッキに加えます。
   4 人の置換基の CIP 順位からカーボの立体（R/S）が決まり、ボーナスが変わります。
   - (R)-カーボ: 各戦闘の 1 ターン目、手札 +1
   - (S)-カーボ: 最大 HP +10
2. **毎ターン手札 6 枚・エネルギー 3**。試薬カード 1 枚＋補助カード（何枚でも）＋溶媒＋温度で「反応開始」。1 回反応すると 1 ターン（1 日）が終わります。
3. 敵の行動は 3 種類: **アルキル化攻撃**（HP ダメージ）、**湿気**（次のターン、フラスコに水が混入）、**加熱の呪い**（次のターン強制還流）。MS 4Å と氷浴で打ち消せます。
4. フラスコに残った **目的物の割合が収率**。原料がほぼ消えると自動で精製、途中で「後処理して精製」も可能。
5. 6 戦の平均収率でランクが決まります。

## 反応エンジン（`js/chem.js`）

教科書レベルの経験則で、基質の級数 × 試薬の性格 × 溶媒 × 温度から経路（SN1 / SN2 / E1 / E2）と生成物の分布を決めます。

| 実装していること | 例 |
|---|---|
| 試薬の分類（強求核・弱塩基 / 強求核・強塩基 / かさ高い塩基 / 弱求核剤） | 第二級 + NaOEt → E2 80% |
| 溶媒効果 | 非プロトン性極性溶媒で SN2 加速、Na 塩は THF に溶けない、t-BuOK はアセトンを自己縮合させる |
| Zaitsev / Hofmann | 2-ブロモ-2-メチルブタン: EtO⁻ → 70:30、t-BuO⁻ → 28:72 |
| 立体化学 | SN2 で反転、SN1 でラセミ化、トシル化は保持、PBr₃・光延は反転、エステルのけん化は保持 |
| カルボカチオン転位 | 3-メチル-2-ブチルカチオン → 1,2-ヒドリドシフト → 第三級 |
| その他 | Finkelstein（アセトン中で NaBr 沈殿）、I⁻ 交換によるラセミ化、アルコキシドとアルコール溶媒の交換、HBr の Markovnikov 付加、Ag⁺ によるイオン化促進、18-クラウン-6 |

数値はゲーム用に丸めた目安です。実際の反応はもっと複雑です。

### テスト

`tests.html` をブラウザで開くと、反応エンジンと問題データのテスト（35 件）が走ります。

```bash
py -m http.server 8765
```

で起動して `http://localhost:8765/tests.html` を開いてください。

## ファイル構成

```
index.html        画面の骨組み
style.css         ドット絵風 UI
js/chem.js        反応エンジン（DOM 非依存）
js/data.js        カード・仲間・戦闘データ
js/mol.js         構造式の描画（SmilesDrawer）
js/questions.js   バトルで出す問題（難易度 4 段階 × 各 10 問、第1章分）
js/game.js        画面とターン進行
lib/              SmilesDrawer 2.1.7（MIT License）
tests.html        エンジンのテスト
```
